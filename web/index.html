POST /quote/generate

The endpoint accepts a JSON request containing a messages array and optional rendering settings. The deployed application also exposes the same generator through the PNG and WebP extension routes above.

Request example

{
  "backgroundColor": "#1b1429",
  "width": 512,
  "height": 768,
  "scale": 2,
  "emojiBrand": "apple",
  "messages": [{
    "from": {"id": 1, "name": "User"},
    "text": "Hello world!",
    "avatar": true
  }]
}

Common parameters

FieldTypeDescription
messagesarrayRequired list of quote messages.
backgroundColorstringBackground color, CSS color, random, or a slash-separated gradient.
width / heightnumberLayout dimensions before scaling.
scalenumberRendering scale from 1 to 20; default is 2.
emojiBrandstringEmoji set used by the renderer, with Apple as the default.
formatstringpng or webp for quote output.
extstringpng or webp for a direct binary response.

Message object

Each message requires from. The renderer accepts Telegram-style sender information and optional media, reply, entities, and voice data.

FieldTypeDescription
fromobjectSender information such as id, first_name, last_name, name, username, and photo data.
textstringMessage text.
entitiesarrayTelegram text entities such as bold, italic, code, links, hashtags, and custom emoji.
avatarbooleanWhether the sender avatar is shown.
replyMessageobjectOptional replied-to message, including name, text, entities, chat ID, and optional sender information.
mediaobject|arrayOptional media URL or Telegram file data.
mediaTypestringsticker for stickers; otherwise text/image media.
mediaCropbooleanWhether media should be cropped to maintain proportions.
voiceobjectOptional waveform data for voice messages.

Response

Without ext, the API returns a JSON envelope containing the generated image. With ext=png or ext=webp, it returns image bytes directly.

{
  "ok": true,
  "result": {
    "image": "<base64 string>",
    "type": "quote",
    "width": 512,
    "height": 359
  }
}

Direct image responses set the corresponding image content type and include quote metadata headers.

Errors

The API reports validation failures such as query_empty, messages_empty, and empty_messages. Requests over the configured rate limit receive HTTP 429.

{"error":"query_empty"}
{"error":"messages_empty"}
{"error":"empty_messages"}

Direct file extensions

Use the extension routes when your client needs image bytes instead of a base64 JSON response.

POST /quote/generate.png
POST /quote/generate.webp
