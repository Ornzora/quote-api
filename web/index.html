Quick start

Send a JSON POST request to /quote/generate. The hostname below is filled from the page's current origin.

POST __ORIGIN__/quote/generate
Content-Type: application/json

{
  "messages": [
    {
      "from": { "id": 1, "name": "Test User" },
      "text": "Hello world!",
      "avatar": true
    }
  ]
}

Request

The request body is merged with query parameters by the API middleware. messages must be a non-empty array.

FieldTypeRequiredBehavior
botTokenstringNoUsed as the Telegram bot token. Falls back to the server's BOT_TOKEN.
typestringNoquote, image, or stories. When omitted, the generated quote canvas is returned.
formatstringNoUsed by the quote type: png or WebP output.
extstringNoSet by the .png or .webp route, or supplied as a request property, to return image bytes instead of JSON.
backgroundColorstringNoHEX/CSS color, random, or slash-separated color values. A leading // creates a transparent variant.
widthnumberNoQuote canvas width before scaling.
heightnumberNoQuote canvas height before scaling.
scalenumberNoClamped to 1–20. Defaults to 2.
emojiBrandstringNoKnown bundled brands include Apple, Google, Twitter, JoyPixels, and Blob. Unknown values fall back to Apple.
messagesarrayYesOne or more message objects.

Message

Each message is normalized before rendering.

FieldTypeBehavior
fromobjectSupports id, first_name, last_name, name, username, photo, and emoji_status.
textstringMessage text.
entitiesarrayTelegram-style entities, including formatting and links supported by the renderer.
avatarbooleanControls whether the avatar is rendered.
replyMessageobjectQuoted reply context. Missing chatId and entity data are normalized by the generator.
mediaobject|arrayMedia URL or Telegram file data. Arrays are supported by the media selection path.
mediaTypestringMedia presentation metadata, including sticker/video/GIF cases.
mediaCropbooleanControls the alternate media selection/crop path.
voiceobjectVoice waveform data used to render a voice-message row.

Entities

Entities use Telegram-style offsets and lengths. The renderer defines handling for formatting, mentions/links, and custom emoji.

"entities": [
  { "type": "bold", "offset": 0, "length": 5 },
  { "type": "italic", "offset": 6, "length": 6 },
  { "type": "code", "offset": 13, "length": 10 },
  { "type": "text_link", "offset": 24, "length": 4, "url": "https://example.com" }
]

Reply

Set replyMessage to add reply context above a message. Missing reply metadata is filled during normalization.

"replyMessage": {
  "name": "Charlie",
  "text": "How's the weather today?",
  "entities": [],
  "chatId": 123456789,
  "from": {
    "id": 123456789,
    "name": "Charlie",
    "photo": { "url": "https://example.com/avatar.jpg" }
  }
}

Media

Media may contain a url or Telegram file information. Arrays are accepted by the generator.

"media": { "url": "https://example.com/image.jpg" }

"media": { "file_id": "AgACAg...", "width": 800, "height": 600 }

Voice

A voice object can provide waveform samples that the renderer turns into a voice-message row.

"voice": {
  "waveform": [0, 4, 8, 16, 12, 8, 4, 8, 16, 12, 8, 4, 0]
}

Output

Without ext, the API returns JSON with ok: true and the generator result. The image is base64.

{
  "ok": true,
  "result": {
    "image": "<base64 string>",
    "type": "quote",
    "width": 512,
    "height": 359
  }
}

When ext is png or webp, the response body is image bytes and the API sets content-type, quote-type, quote-width, and quote-height headers.

Background

backgroundColor is parsed by the color helper. A slash separates two colors. A leading // creates a semi-transparent variant. The exact resulting composition is handled by the renderer and image types.

Errors and limits

Known generator errors include query_empty, messages_empty, and empty_messages. Unknown methods return method not found. The application rate limiter allows 20 requests per IP in a 55-second window; requests carrying the configured bot token are whitelisted.

{
  "ok": false,
  "error": {
    "code": 429,
    "message": "Rate limit exceeded. See \"Retry-After\""
  }
}

Examples

JavaScript

const response = await fetch('__ORIGIN__/quote/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    backgroundColor: '#f68ac9',
    scale: 2,
    messages: [{
      from: { id: 1, name: 'Test User' },
      avatar: true,
      text: 'Hello world!'
    }]
  })
})

const data = await response.json()
const image = Buffer.from(data.result.image, 'base64')

Python

import base64, requests

payload = {
  'messages': [{
    'from': {'id': 1, 'name': 'Test User'},
    'text': 'Hello world!',
    'avatar': True
  }]
}

r = requests.post('__ORIGIN__/quote/generate', json=payload)
data = r.json()
image = base64.b64decode(data['result']['image'])

open('quote.png', 'wb').write(image)
