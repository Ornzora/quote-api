Quick start

Send a POST request to /quote/generate with a JSON body containing at least one message.

POST /quote/generate
Content-Type: application/json

{
  "backgroundColor": "#f68ac9",
  "messages": [
    {
      "from": { "id": 1, "name": "Test User" },
      "text": "Hello world!"
    }
  ]
}

Request

The request properties are read from both the query string and JSON body. Body values take precedence when the same property is supplied.

PropertyPurpose
botTokenOptional Telegram bot token. The server environment token is used when omitted.
typequote, image, or stories.
formatpng or webp for quote output.
backgroundColorBackground color accepted by the renderer.
width / heightQuote canvas dimensions.
scaleRender scale, clamped by the generator.
emojiBrandEmoji set used by the renderer: apple, google, twitter, joypixels, or blob.
messagesNon-empty array of message objects.

Messages

A message can contain from, text, entities, avatar, replyMessage, media, mediaType, mediaCrop, and voice. The renderer also normalizes missing sender/photo fields.

Entities

Supported entity types include formatting such as pre, code, and pre_code, plus Telegram-style mention/link entities including mention, text_mention, hashtag, email, phone_number, bot_command, url, and text_link.

Reply and media

replyMessage can describe the quoted message. media can provide a media URL with optional media type and crop settings.

Output

Without a file extension, the API returns a JSON envelope containing ok: true and a result object with the generated image as base64 plus the generated dimensions.

{
  "ok": true,
  "result": {
    "image": "<base64>",
    "type": "quote",
    "width": 512,
    "height": 359
  }
}

Using .png or .webp returns image bytes directly with metadata headers for quote type and dimensions.

Errors

Invalid or missing requests return an error envelope with an HTTP 400 status. Known generator errors include query_empty, messages_empty, and empty_messages. Unknown API methods return method not found.

The server also applies a rate limit of 20 requests per IP over a 55-second window. A valid configured bot token is whitelisted by the current middleware.
