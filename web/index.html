Quick start

Send a JSON POST request to /quote/generate. The page automatically resolves the current origin, so deployment-specific hostnames are not embedded in examples.

POST __ORIGIN__/quote/generate
Content-Type: application/json

{
  "messages": [
    {
      "from": { "id": 1, "name": "Test User" },
      "text": "Hello world!",
      "avatar": true
    }
  ]
}

Request parameters

The generator reads these top-level properties. messages is required; the remaining fields are optional.

FieldTypeRequiredBehavior
botTokenstringNoTelegram bot token. Falls back to BOT_TOKEN.
typestringNoquote, image, or stories. Other values use the raw generated quote canvas.
formatstringNopng or webp when type is quote.
extstringNoWith png or webp, the response is returned as image bytes instead of base64 JSON.
backgroundColorstringNoHEX, CSS color name, random, gradient using /, or transparent variant using a leading //.
widthnumberNoLayout width before scaling.
heightnumberNoLayout height before scaling.
scalenumberNoClamped to 1–20. Default is 2.
emojiBrandstringNoBundled emoji brand. Defaults to apple.
messagesarrayYesOne or more message objects.

Message object

Each item in messages is normalized before rendering.

FieldTypeBehavior
fromobjectSender data. Supports id, first_name, last_name, name, username, photo, and emoji_status.
textstringMessage text.
entitiesarrayTelegram-style text entities such as bold, italic, code, links and custom emoji.
avatarbooleanWhether the avatar is rendered.
replyMessageobjectQuoted reply context. Supports name, text, entities, chatId and from.
mediaobject|arrayMedia URL or Telegram file data. Arrays use the last item, or the second item when cropping is enabled.
mediaTypestringUsed for media presentation, including sticker/video/GIF badges.
mediaCropbooleanControls the alternate media selection/crop path.
voiceobjectWaveform data rendered as a voice-message row.

Text entities

Entities use Telegram-style offsets and lengths. Supported behavior is determined by the renderer's entity handling. A custom emoji entity can provide custom_emoji_id.

"entities": [
  { "type": "bold", "offset": 0, "length": 5 },
  { "type": "italic", "offset": 6, "length": 6 },
  { "type": "code", "offset": 13, "length": 10 },
  { "type": "text_link", "offset": 24, "length": 4, "url": "https://example.com" },
  { "type": "custom_emoji", "offset": 29, "length": 2, "custom_emoji_id": "5368324170671202286" }
]

Reply messages

Set replyMessage to add reply context above a message. The server fills missing chatId and reply entity defaults during normalization.

"replyMessage": {
  "name": "Charlie",
  "text": "How's the weather today?",
  "entities": [],
  "chatId": 123456789,
  "from": {
    "id": 123456789,
    "name": "Charlie",
    "photo": { "url": "https://example.com/avatar.jpg" }
  }
}

Media

Media can be an object containing url or Telegram file information. An array is also accepted. Animated media may use a thumbnail path.

"media": { "url": "https://example.com/image.jpg" }

"media": { "file_id": "AgACAg...", "width": 800, "height": 600 }

"media": [
  { "file_id": "AgACAg...1" },
  { "file_id": "AgACAg...2" }
]

Voice

A voice object can provide waveform samples. The renderer converts the numeric waveform into a visual voice row.

"voice": {
  "waveform": [0, 4, 8, 16, 12, 8, 4, 8, 16, 12, 8, 4, 0]
}

Output

Without a URL extension, the API helper returns a JSON envelope with ok: true and the generator result. The result contains image, type, width, height, and ext; the image is base64 when no extension is requested.

{
  "ok": true,
  "result": {
    "image": "<base64 string>",
    "type": "quote",
    "width": 512,
    "height": 359,
    "ext": "png"
  }
}

With /quote/generate.png or /quote/generate.webp, the response body is the generated image bytes and response headers include the image content type plus quote metadata.

Backgrounds and layout

backgroundColor is parsed by the color helper. A slash separates two colors for a gradient. A leading // creates a semi-transparent variant. width, height, and scale affect the quote canvas before optional type-specific composition.

Errors and limits

Validation can return query_empty, messages_empty, or empty_messages. Unknown methods return method not found. The application rate limiter allows 20 requests per IP in a 55-second window; requests carrying the configured bot token are whitelisted.

{
  "ok": false,
  "error": {
    "code": 429,
    "message": "Rate limit exceeded. See \"Retry-After\""
  }
}

Examples

JavaScript

const response = await fetch('__ORIGIN__/quote/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    backgroundColor: '#f68ac9',
    scale: 2,
    messages: [{
      from: { id: 1, name: 'Test User' },
      avatar: true,
      text: 'Hello world!'
    }]
  })
})
const data = await response.json()
const image = Buffer.from(data.result.image, 'base64')

Python

import base64, requests

payload = {
  'messages': [{
    'from': {'id': 1, 'name': 'Test User'},
    'text': 'Hello world!',
    'avatar': True
  }]
}
r = requests.post('__ORIGIN__/quote/generate', json=payload)
data = r.json()
image = base64.b64decode(data['result']['image'])
open('quote.png', 'wb').write(image)
